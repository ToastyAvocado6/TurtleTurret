# 🐢 Turtle Turret

A fast-paced 2D arcade shooter built with Python and Pygame Zero. Aim 360 degrees to blast ocean garbage with bubbles and eat lettuce to survive!

## ✨ Features
* **Precise Aiming:** The turtle tracks your mouse pointer perfectly.
* **Juicy Animations:** Features satisfying weapon recoil and pulsing water ripples.
* **Smart Performance:** Uses asset caching to keep the gameplay smooth and lag-free.
* **Ramping Difficulty:** Plastic spawns faster the longer you stay alive.
