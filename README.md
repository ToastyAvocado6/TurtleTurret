# 🐢 TURTLE TURRET

A fast-paced 2D arcade shooter built with Python and Pygame Zero. Aim in 360 degrees to blast floating ocean garbage with bubbles and eat healthy lettuce to survive!

## 🕹️ Installation Guide

### System Requirements
* Mac or Windows (preferably Mac)
* **Software:** No external software or Python installation is required to run/execute

### How to Download and Run the Game
1. Download the game's release folder zip archive.
2. Extract the contents of the zip file to a location of your choice on your computer.
3. Open the extracted folder and open the folder named `TurtleTurret`.
4. Double-click the **MAIN** executable file to launch

---

## 🎮 Playing the Game

### Objective
You control a stationary sea turtle in the center of the screen. Protect yourself from incoming plastic pollution by shooting bubbles, while absorbing lettuce to heal. Survive for as long as possible against a steadily increasing spawning rate.

### Controls
* **Mouse Movement:** Move the cursor to rotate the turtle and aim in 360 degrees.
* **Spacebar:** Fire a high-speed bubble projectile toward your mouse cursor. 
* **Escape Key:** Safely quit and exit the game session at any time.

### Scoring System
* Your score is based entirely on **Survival Time**. 
* Aim to last as many seconds as possible to set a personal high score!

### Win/Lose Conditions
* The goal is to maximize your total survival time against a ramping difficulty curve.
* You start with **5 Hearts** of health. Getting struck by a piece of plastic bottle deals 1 damage. If your health drops to **0 / 5 Hearts**, it is immediate Game Over. 

💡 *Tip: Green lettuce pieces will heal you by +1 heart if you let them reach you, up to a maximum cap of 5 hearts!*
